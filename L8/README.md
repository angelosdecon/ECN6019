# Week 8: Cournot workout (+ guess ⅔ of the average, + spot the equilibrium)

Order in the lecture (26 Nov 2026): the **Cournot workout** first; the **⅔ game** only if there is time; **Spot the equilibrium** is optional extra practice.

1. **Cournot workout** (self-paced, like Weeks 6–7). Each phone gets its own market, p = a − Q with MC = c (16 sets, a − c a multiple of 12 so every answer is a whole number; none repeats the lecture, the recording, PS8 or the exams). Six multiple-choice steps, one try each, a Hint button, "What we know so far", ✓/✗ with the working and a tip for the mistake picked: profit → first-order condition → best response → q* → p* → profit. A best-response diagram drawn to scale fills in (BR₁ after step 3, BR₂ and the Nash equilibrium after step 4). Bonus: three firms (q*, p*, what happens as n grows). Then "Try another market" (kept on the phone) or "More practice: spot the equilibrium".
2. **Guess ⅔ of the average** (whole class, two rounds, results between rounds). Round results are frozen when the dashboard moves to a results step. "What game theory predicts" shows the ladder 100 → 66.7 → … → 0 and the class averages. Can stop after round 1.
3. **Spot the equilibrium** (self-paced): six payoff matrices per phone; tap every pure-strategy Nash equilibrium, or "none".

Dashboard steps (Next/Back or arrow keys): Join → Cournot workout (live) → Cournot results (% right first time, % hints, most common mistake per step; bonus chart) → ⅔ round 1 → results → round 2 → results → what game theory predicts → (optional) Spot live → Spot results → End. You can jump straight to End from any step.
